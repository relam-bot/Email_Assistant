Smart Email Assistant (Gmail + Gemini AI)

An Agentic AI-powered email assistant that automatically fetches unread Gmail emails, summarizes them, and suggests professional replies. Built with Streamlit, Python, and Google Gemini API, it streamlines email management by combining AI understanding with interactive action.

🚀 Features

🔄 Auto-fetch unread emails using Gmail IMAP

🤖 AI-powered summarization of every email (via Gemini API)

💬 Context-aware reply generation with multiple suggestions

✏️ Edit and customize suggested replies

📤 Send replies directly through Gmail SMTP

📊 Unread email counter for quick overview

⏱️ Auto-refresh every 5 seconds for real-time inbox updates

🛡️ Agentic AI workflow:

Observe (fetch unread emails)

Reason (summarize and generate replies)

Act (send replies)
